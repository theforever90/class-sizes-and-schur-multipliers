# Class sizes and Schur multipliers

For 17 finite simple groups, this GAP computation checks that, for every nonidentity element of prime-power order $p^a$, the $p'$-part of its conjugacy class size does not divide the order of the group's Schur multiplier.

- [Code](Code.md) gives the statement, multiplier data and GAP program.
- [Output](Output.md) records the results for all 330 classes checked.
